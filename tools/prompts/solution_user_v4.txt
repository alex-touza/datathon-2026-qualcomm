Solve the problem below. Write the hint ladder in three parts, and an adapted
version of the problem for students with dyscalculia or dyslexia. Write every
text field in the same language as the problem.

Problem:
{{PROBLEM}}

Options:
{{OPTIONS}}

Correct option: {{LABEL}}) {{VALUE}}

Part 1 — Nudge:
One sentence, at most 15 words. Name the first thing to look at, count, or try.
Do not calculate. Do not mention the final answer, any option letter, or any
option value. This hint must be deliberately small.

Part 2 — Work:
The next calculation or step(s), showing intermediate values. Stop before the
final answer. Do not mention the correct option letter. Do not write the final
value, and do not write any number that equals it. Numbers that the problem
already gives may be used freely.

Part 3 — Conclude:
At most two short sentences. If you verify the result, do it here and do it
first. Then the very last line must be exactly:

Correct option: {{LABEL}}) {{VALUE}}

Nothing may follow that line: no sentence, no number, no explanation after the
value.

Adaptation (numbers as variables):
- "template": the problem text, unchanged except that every data number written
  in digits becomes a placeholder {n1}, {n2}, ... in order of appearance. Drop the
  leading problem number ("13."). Leave number words ("three", "twice") as words.
  The same number used twice with the same meaning uses the same placeholder.
- "variables": for each placeholder, "default" (the number in the problem) and
  "small" (a smaller, friendlier number that keeps the problem valid and the
  answer a small whole number when possible). If the numbers cannot change
  without breaking the problem, set "small" equal to "default".
- "answer_formula": an arithmetic expression over n1, n2, ... (+ - * / // % **
  and parentheses only) that gives the correct value with the default values.
  Use null if the answer is not a formula of the given numbers (a figure, a
  choice, a logic puzzle).
- "steps_template": the worked solution as 2 to 5 short numbered lines that
  use the placeholders. Write a computed value as {=expression}, e.g.
  "{n1} + {n2} = {=n1+n2}". It must read correctly with the default and with
  the small values. Do not name the option letter here.
- "dyslexia_template": the same problem as 3 to 6 short lines, one idea per
  line, at most 12 words per line, plain words, the question on the last line.
  Use the same placeholders. Separate lines with \n.
If the problem has no data numbers, use "variables": {}, "answer_formula": null,
and still write "template", "steps_template" and "dyslexia_template".

Rules:
- Use only the quantities and information given in the problem.
- Do not invent numbers, facts, or a different correct option.
- The three parts together must form one coherent solution.
- Keep part1 + part2 + part3 under 120 words.
- If the problem is in Catalan, write every text field in Catalan.

Return exactly this JSON object and nothing else:
{"part1": "...", "part2": "...", "part3": "...",
